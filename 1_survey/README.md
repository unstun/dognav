# 1_survey

`1_survey/` 用于 nav 文献调研材料。

```text
1_survey/
├── README.md
├── papers/                 # PDF 原文，命名 AuthorYear_ShortTitle.pdf
└── YYYY-MM-DD_<topic>/      # 每轮调研一个目录
```

## papers/ 命名规范

`AuthorYear_ShortTitle.pdf`，例如 `Rudin2022_LearningToWalkInMinutes.pdf`。

与 `.pipeline/literature/README.md` 中的 CitationKey 保持一致。
