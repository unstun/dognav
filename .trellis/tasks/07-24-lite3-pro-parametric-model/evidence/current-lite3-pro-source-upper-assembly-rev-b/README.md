# Current Lite3 Pro source upper assembly Rev B

This package keeps the source-backed J20A, MID-360, and S410 transforms from
Rev A, replaces the photo-only compute keep-out with the scan-registered Rev B
keep-out, and adds the nominal compute enclosure with its two front-side
recesses for visual review.

The nominal notched enclosure is a scan/photo envelope. The larger red
rectangular keep-out remains the collision rule. No current-Pro receiver,
thread, usable depth, lower adapter, screw length, strength result, or print
release is inferred here.
