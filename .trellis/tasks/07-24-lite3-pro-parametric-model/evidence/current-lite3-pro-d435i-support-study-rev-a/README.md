# Current Lite3 Pro D435i support study Rev A

This package sweeps the official D435i nominal 90 x 25 x 25 mm envelope in
front of the registered J20A, MID-360, and S410 upper assembly.  The camera is
given a 20-degree downward optical direction and a fixed 2 mm margin behind the
photo-measured nose edge.

The sweep selects only collision-free placement heights.  It does not create a
support solid or release a printable part.
