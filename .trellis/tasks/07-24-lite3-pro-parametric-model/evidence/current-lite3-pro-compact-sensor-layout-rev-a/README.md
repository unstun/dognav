# Current Lite3 Pro Compact Sensor Layout Rev A

This package answers the first packaging question after physical measurement:
the old `153.7 mm` carrier is too long for the current front zone, but a compact
source-geometry sensor arrangement can fit in plan.

The CAD assembly intentionally contains a zero-thickness support planning
surface, not a printable bracket. It preserves the Mid-360 and S410 source
B-reps, represents the unconverted official D435i CAD by the official
datasheet envelope, and checks all three against the uncertainty-expanded
compute enclosure.

Receiver threads/depths, the centre candidate's load path, optical directions,
cables, fastener access, structural ribs, material, and print orientation are
the next gates.
