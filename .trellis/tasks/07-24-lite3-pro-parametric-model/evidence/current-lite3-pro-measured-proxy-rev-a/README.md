# Current Lite3 Pro Photo-Measured Proxy Rev A

This evidence package provides the first current-hardware replacement for the
rejected older Lite3 robot interface. It contains:

- an editable FreeCAD proxy;
- a neutral STEP with the photo deck silhouette, nominal compute enclosure,
  and three separately named axis markers;
- a separate uncertainty-expanded enclosure keep-out STEP;
- a top measurement map and an isometric layout render;
- machine-readable validation tied to the physical-photo hashes.

The geometry is intentionally non-printable. Thread size, usable depth, the
centre candidate's receiver role, and local service/cable volumes remain open.
Those values must be verified before a lower-adapter solid or fastener length
is generated.
