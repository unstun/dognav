# Status

`photo_measured_proxy_only_receiver_contract_open`

This package converts Dr Sun's current Lite3 Pro tape-measure photographs into
a lightweight B-rep layout proxy and explicit axis markers. It is not official
Lite3 CAD and contains no printable lower adapter.

Blue cylinders mark the two front axes measured at `65.0 +/- 1.0 mm`. The
yellow cylinder marks the visible centre candidate approximately `75 mm`
behind the front row; its mounting role, thread, usable depth, receiver
material, and load path are unverified. The compute enclosure is represented
by a `200 x 100 x 50 mm` nominal photo envelope and a separate
uncertainty-expanded collision keep-out.

No STL, screw selection, fabrication release, physical fit claim, or robot
actuation is authorized by this package.
