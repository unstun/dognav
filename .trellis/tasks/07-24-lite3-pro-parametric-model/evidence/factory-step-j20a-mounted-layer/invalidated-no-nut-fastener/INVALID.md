# Invalidated no-nut fastening demo

This artifact set is superseded and must not be used as the current fastening
demonstration.

Reason: it correctly visualized the user-confirmed A7/A8 to B4/B5 hole mapping,
but it stopped after inserting two short screws and omitted the two far-side
nuts explicitly required by Dr Sun.

The replacement demonstration uses two M3x12 visual through-bolt candidates and
two far-side hex-nut visual candidates. The dimensions remain a visualization
contract pending physical standard-part selection.
