# Invalidated front-fastener demo

This artifact set is invalid and must not be used as assembly evidence.

Reason: when the M3 screw-length demonstration changed from M3x8 to M3x6,
the two obsolete M3x8 occurrences were not removed. The model and animation
therefore contained two overlapping front screw sets. The candidate front-hole
mapping also remains pending human confirmation.

The active independent Fusion demonstration has had all four front screw
occurrences removed. The original Lite3 assembly remains unchanged.
