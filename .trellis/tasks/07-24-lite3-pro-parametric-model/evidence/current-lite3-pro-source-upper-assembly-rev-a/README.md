# Current Lite3 Pro source upper assembly Rev A

This package registers the related-source J20A second-layer bracket, the
official MID-360 B-rep, and the related-source S410 guard from their preserved
hole axes and seating planes.  J20A is centred inside the current-Pro measured
front zone and retains its source 15-degree LiDAR mounting direction.

The assembly is independent of the current-Pro chassis receiver.  It proves
source-axis registration, compact packaging, and modeled collision clearance;
it does not release a printable lower adapter or select screw lengths.

The STEP export contains only J20A, S410, and MID-360.  The FCStd also contains
the current-Pro expanded compute-box keepout for review.
