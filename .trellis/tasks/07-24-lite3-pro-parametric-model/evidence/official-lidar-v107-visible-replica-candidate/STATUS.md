# Rejected J17A-derived visible candidate

Status: rejected on 2026-07-26.

This candidate removed the earlier engineered rails, hidden receiver proxies,
and clearance-driven sensor translation, but it still imported the J17A
carrier, J20A adapter, and S410 guard geometry from the Venture FAST-LIVO2
hardware package.  It therefore remains an adaptation of another assembly and
must not be presented as a replica of the factory Lite3 LiDAR V1.0.7 assembly.

The directory is retained only as negative evidence.  Its renders, manifest,
and FCStd file are not acceptance artifacts and carry no factory-CAD,
assembly-fit, or print-readiness claim.
