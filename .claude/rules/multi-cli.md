# Multi-CLI Collaboration

The main-session coordinator depends on the current CLI entry. In Claude Code/Droid main sessions, Codex can be accessed through the official `openai/codex-plugin-cc` plugin via slash commands (`/codex:rescue`) or subagent (`codex:codex-rescue`). It uses app-server JSON-RPC and automatically inherits `AGENTS.md`. **Cursor exception**: Codex is always reached through a manual task package generated by the main session; Dr Sun pastes it into Codex App or runs commands in a local terminal, and the main session only reviews returned results. **Codex main entry**: Codex reads `AGENTS.md` and the trusted `.codex/` layer directly. For complex harness checks, prefer spawning `harness_explorer` and `harness_reviewer` in parallel. Both custom agents default to `sandbox_mode = "read-only"`, while actual permissions still depend on the parent session runtime config.

For review, use `/codex:review` or `/codex:adversarial-review` on the Codex side, `gemini-review` on the Gemini side, or `dual-review` for cross-review.

For task delegation, Claude Code/Droid may use `/delegate` (mode B: spawn `codex:codex-rescue` in the background) or `/delegate-offline` (mode A: generate a prompt for an independent terminal running `codex` CLI). **Cursor defaults to mode A only**.

See `.pipeline/survey/multi-ai-workflow.md`.
