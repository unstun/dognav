# 记忆系统详细结构

## bigmemory/(按需拉取,透明读写)

- `热区/状态简报.md` — 当前项目状态(≤1500字)
- `热区/未关闭决策.md` — 未关闭的研究/技术决策(≤1200字)
- `热区/近期改动.md` — 最近 7 天改动摘要(≤1000字)
- `冷区/改动记录/` — 按天归档:YYYY-MM-DD.md(只追加)
- `冷区/踩坑记录/` — 按天归档(只追加)
- `冷区/调研记录/` — 按天归档(只追加)
- `冷区/心路历程/` — 按天归档(只追加)
- `冷区/里程碑/` — 按天归档(只追加)
- `冷区/偏好.md` — 用户偏好(单文件)
- `冷区/工作流.md` — 标准工作流(单文件)
- `格式规范.md` — 热区容量预算 + 冷区文件格式模板

完整聊天记录不再归档到 bigmemory；只保留可复查摘要和项目状态。

**读写规则**:冷区按天文件只追加不覆写,热区全量重写且须遵守容量预算。

## .pipeline/(项目知识库)

- `terminology/` — 术语规范表
- `literature/` — 文献库(index.md 为主表)
- `survey/` — 综述库(每个调研主题一个 `.md`)
- `experiments/` — 实验台账(每轮实验一个 `YYYYMMDD_<topic>.md`)

## 记忆出入口

**入口(按需)**:AI 判断需要项目历史上下文时,主动调用 `memory-retrieval` skill。
**出口(手动)**:Dr Sun 调用 `/archive`,执行分诊 + 冷区归档 + 热区刷新。

## 何时必须调用 memory-retrieval(不可自我合理化绕过)

### 白名单 A — Dr Sun 提问触发(命中任一必调)

- "现在做到哪 / 进度如何 / 状态怎样 / 最近在做什么"
- "上次 / 昨天 / 之前 / 前几天做了什么"
- "还有什么没做完 / 未关闭决策 / 待办"
- 明确说"回忆 / 检索 / 查一下之前 / 翻一下记录"
- 任何以"现在""最近""上次""还"开头且语义指向历史的问句

### 白名单 B — AI 自发场景(命中任一必调)

- 准备写论文 section → 回忆 Contract / 实验结果 / 相关文献
- 准备做实验决策(算法/超参/仿真配置) → 回忆之前的配置和结论
- 准备改跨模块代码 → 回忆架构决策和既有约定
- 准备写 Research Contract → 回忆既有 contract 和 hypothesis 演化

### 黑名单 — 以下场景无需调用

- 纯代码/工具语法问题("Python 这个函数怎么写"、"git reset 怎么用")
- Dr Sun 单行命令式执行("跑测试"、"commit"、"格式化这个文件")
- 显式指向外部资源("查 arXiv""读这篇 paper")
- 任务闭环在当前 session 可完成且不跨会话

### 反合理化检查

出现以下内心独白时立即停,调 skill:
- "我还记得..." / "应该是..." / "大概是..."
- "热区文件我直接读就行"(❌ 热区可能过期,且违反本规则)
- "这个问题我刚才已经答过"(刚才答的可能就是基于幻觉)

违反本规则的典型表现:Dr Sun 问"现在做到哪"→ AI 直接 Read 热区三文件而未走 skill。
