# 2026-08-20 Office R2.0.1 踩坑记录

- 5070 Ti host 没有 `/opt/ros/foxy`；Foxy bridge 必须在已钉住的容器内构建。
- 源码同步后若不重建 install tree，launch 仍可能使用旧参数；preflight01
  因此被新的 fail-closed gate 正确拒绝。
- 10 秒 run 的订阅启动损失足以让 95/101 低于 0.95；简单调整 launch
  节点顺序不能消除竞态。
- 单独容器即使 READY、容器身份相似，也可能通过不了此环境的 ROS 2 DDS；
  preflight04/05 的零观测说明不能把“进程已启动”等同于“真云已收到”。
- 最终做法是在原同容器 subscriber ready 前暂挂 Isaac，再恢复；不改仿真
  时间和传感器频率。
- 一次本地全量测试命令漏了项目 PYTHONPATH，另一次 ledger validator 漏了
 必需参数；这属于操作者命令错误，不能包装成代码回归。
- 8.6 GiB 结果树的大头是 8.2 GiB rosbag；先做无损 zstd 归档、归档哈希、
  解包后递归哈希，才能在慢链路下保持完整证据边界。
