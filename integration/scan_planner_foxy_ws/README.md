# SCAN-Planner Foxy Overlay

This overlay derives from the immutable SCAN ROS 2 community snapshot recorded
under `references/upstream/2026-08-13_scan-planner-ros2-community/`.

The accepted runtime contains only six planner packages and builds only the
planner node and closed-loop velocity controller. Isaac Sim owns the Lite3
physics, locomotion policy, 3D sensor rendering, and simulator-truth pose.

`foxy_isaac_closed_loop.launch.py` must never start the upstream Go2
description, Gazebo Fortress, kinematic simulator, open-loop controller, or
visualization gait publisher. The overlay is a project Foxy compatibility
port, not an upstream Foxy release or upstream reproduction.

For the accepted articulated Lite3 simulation, the port additionally owns the
measured-pose trajectory progress gate, conservative Lite3 planning envelope,
LiDAR occlusion shadow, and event-driven safety replanning configuration. These
are project integration changes, not claimed upstream defaults. The complete
reviewable diff is generated by
`references/upstream/2026-08-13_scan-planner-ros2-community/generate_foxy_port_patch.sh`.
